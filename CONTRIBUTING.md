# Contributing

>Thanks for your interest in contributing to **tgmailbot**.

This is primarily a **portfolio project**, built to demonstrate practical backend and automation work. That said, contributions, improvements, bug fixes, and ideas are absolutely welcome.

## Getting Started

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Run the tests.
5. Open a pull request with a short description of what you changed.

## What You Can Contribute

Some good areas to contribute to include:

* Bug fixes
* New source adapters
* Improvements to normalization or deduplication
* Tests
* Documentation
* Performance improvements
* Small quality-of-life improvements

Please keep contributions focused and consistent with the project's existing architecture.

## Pull Requests

Please keep PRs small and explain **what changed and why**.

For larger changes, opening an issue first is appreciated so the approach can be discussed before implementation.

Thanks for helping improve the project.
